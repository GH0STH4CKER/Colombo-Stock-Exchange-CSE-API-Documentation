Colombo Stock Exchange API — Documentation

Base URL: https://www.cse.lk/api/ · 93 public data endpoints · example responses show structure only, with placeholder values

Unofficial, reverse-engineered from the cse.lk website. Endpoints may change without notice.

Request formats

Endpoints without parameters accept a plain POST (or GET) with an empty body.

For endpoints with parameters, send the body in the format listed on each endpoint:

BodyContent-TypePython requests
formapplication/x-www-form-urlencodedrequests.post(url, data={...})
multipartmultipart/form-datarequests.post(url, data={...}) also works
jsonapplication/jsonrequests.post(url, json={...})
query— (GET)requests.get(url, params={...})

Endpoints the website calls with multipart/form-data also accept application/x-www-form-urlencoded. Only the json endpoints (boardReason, smd, debtDetailTrades) need a JSON body.

Logos and files: prefix logoUrl / path values with https://cdn.cse.lk/cmt/ (logos) or https://cdn.cse.lk/ (reports and PDFs).
